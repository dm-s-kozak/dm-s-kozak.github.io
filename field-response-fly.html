Field-response / event-fixed page

Field manifestation

The field is not shown directly. The fly lives in its ordinary flyness until an event occurs. Only after the fly is altered does the event become fixed in a card.

The observer does not read the field as an object. The observer sees event → altered fly → event card.

Event source Lightning / discharge acts as the visible source-event. From it come event-traces: impulse, light, plasma glow, dynamic disturbance, and electromagnetic coupling.
The fly is still in ordinary flyness. No event has been fixed yet.
Event 1 — Impulse The fly changed movement. The first field-event is now fixed.
Event 2 — Light The fly changed again after a flash. The second event is fixed.
Event 3 — Plasma / glow A color drift appears in the carrier. The third event is fixed.
Event 4 — Discharge disturbance The carrier dynamics are disturbed. Another event has been fixed.
Event 5 — EM coupling The later event does not show the field itself; it deepens the altered carrier.
The page keeps the event-route. The field is readable through the altered fly, not as a directly visible thing.
